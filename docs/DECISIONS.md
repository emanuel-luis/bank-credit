# Decisions

Decisions taken during the 2026-10 refactor. Low-impact items follow the refactor brief's
recommended option; high-impact ones were answered by the owner.

| # | Date | Decision | Choice | Why |
| --- | --- | --- | --- | --- |
| 1 | 2026-10-25 | The default `SECRET_KEY` committed in `routers/auth.py` (in tree and history) | Remove the fallback and fail fast when `SECRET_KEY` is unset; no history rewrite | The app was a demo and never ran in production with that key, so the old value protects nothing; rewriting a public history costs more than it saves. The key is treated as burned and never reused |
| 2 | 2026-10-25 | Old commit metadata with a work email | Leave it alone | Rewriting history only for author metadata is not worth it; new commits use the personal identity |
| 3 | 2026-10-25 | Configuration | pydantic-settings `Settings` read from env / `.env`; `.env.example` committed | One typed source of configuration; missing required values fail at startup |
| 4 | 2026-10-25 | Database URL variable | `DATABASE_URL` (was `DATABASE_CONNECTION_URI`) | Conventional name used by Docker images, Alembic recipes and hosting platforms |
| 5 | 2026-10-25 | JWT library | PyJWT instead of python-jose | python-jose is unmaintained; PyJWT is the library FastAPI's docs now use |
| 6 | 2026-10-25 | Password hashing | pwdlib with Argon2 instead of passlib + bcrypt | passlib is unmaintained and breaks with recent bcrypt releases; Argon2 is the current OWASP recommendation. Existing demo hashes are regenerated by the seed script |
| 7 | 2026-10-25 | Build backend | `uv_build` instead of poetry-core | The project is managed by uv; the package keeps its `serve` and `populate` console scripts |
| 8 | 2026-10-25 | Python version | 3.12 | Program baseline for applications |
| 9 | 2026-10-25 | App entry point | `create_app()` factory run with `uvicorn --factory` | No work at import time; tests build their own app with test settings |
| 10 | 2026-10-25 | When CI arrives | A minimal backend CI (ruff + pytest) ships in the first PR; frontend, Docker and compose jobs come with the containers PR | Every later merge then has a real gate |
| 11 | 2026-10-25 | Email delivery | Off by default (`MAIL_ENABLED=false`): emails are logged instead of sent | The demo has no SMTP server; tests and compose need no mail credentials |
| 12 | 2026-10-25 | Tool artifacts `frontend/.vite` and `frontend/.bolt` | Untracked and gitignored | Generated by local tooling, not source |
| 13 | 2026-10-25 | Frontend package name | `bank-credit-web` | The scaffold used a real bank's name; a portfolio demo should not carry it |
